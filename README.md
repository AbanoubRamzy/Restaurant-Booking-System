# 🍔 Foodies Restaurant App

A responsive restaurant web application built with HTML, CSS, and JavaScript. Users can browse menu items, filter categories, manage a shopping cart, and reserve tables through a modern and interactive interface.

## ✨ Features

* Dynamic menu rendering
* Category filtering
* Shopping cart with quantity management
* Local Storage persistence
* Table reservation system
* Toast notifications
* Responsive design
* Smooth animations and hover effects

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage API
